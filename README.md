# Zenqara Digital

Proyecto Angular organizado en `paginaZenqara/`, con la página principal separada en HTML, TypeScript y SCSS.

## Desarrollo

```sh
cd paginaZenqara
npm ci --legacy-peer-deps
npm start
```

## Compilación

```sh
npm run build
```

La web compilada se guarda en `dist/browser/`. El repositorio permanece privado.
